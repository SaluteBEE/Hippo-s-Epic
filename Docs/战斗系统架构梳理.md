# 战斗系统架构梳理（Hippo-s-Epic）

> 本文档基于当前代码梳理（BattleManager.cs 1160 行 + 表现层 + UI 层），覆盖**战斗逻辑、前端表现、UI 交互**完整链路。
> UML 图见同目录 `uml/`（类图 battle_class.png / 战斗时序 battle_sequence.png / 回合循环活动图 battle_activity.png）。

---

## 一、系统总览

```
┌────────────────────────────────────────────────────────────────────┐
│                      GameApp（战斗入口/出口）                        │
│  EnterBattle → 创建 BattleManager → 加载 Scene_Battle → 生成角色 → 开始 │
└───────────────┬───────────────────────────────────┬─────────────────┘
                │                                   │
     ┌──────────▼───────────┐           ┌───────────▼───────────┐
     │   战斗逻辑层（纯数据）   │           │   前端表现层（Mono）    │
     │  BattleManager        │  事件驱动  │  BattlePresenter     │
     │  BattleUnit/Action    │ ◄────────► │  BattleStageManager  │
     │  BattleAI             │           │  BattleHealthBar     │
     │  BattleEventQueue     │           │  DamageFx/飘字        │
     └──────────┬───────────┘           └───────────┬───────────┘
                │                                   │
     ┌──────────▼───────────┐           ┌───────────▼───────────┐
     │  ManagerRegistry      │           │  BattleWindow(UI)     │
     │  DataTableManager     │           │  SkillPanel/ItemPanel │
     │  BuffManager(单位内)   │           │  TalkPanel/LogPanel   │
     └──────────────────────┘           └───────────────────────┘
```

**核心设计原则（本项目实测）**：
- **逻辑与表现解耦**：BattleManager 只算数据、发事件；BattlePresenter/BattleStageManager 只做视觉；BattleWindow 订阅事件刷新 UI。
- **事件驱动**：BattleManager 暴露 17 个 C# 事件，UI 与表现层各自订阅，互不依赖。
- **演出回调推进回合**：技能结算后 BattleManager 调 `presenter.PlaySkillSequence(..., onComplete)`，**演出结束回调后才 EndUnitTurn**（保证飘字/倒地完整播放，这是修复 bug 1/2 的核心）。
- **事件队列**：BattleEventQueue 按 6 个时机（RoundStart/TurnStart/StatusCheck/Action/TurnEnd/RoundEnd）延迟处理召唤/伤害/治疗/Buff/技能触发等事件，支持"增援下一轮入场"。

## 二、核心类职责与全部方法说明

### 2.1 BattleManager（战斗逻辑总控，无 Mono 依赖）

| 方法 | 功能 |
|---|---|
| `InitBattle(int battleId)` | 战斗初始化：重置 Phase/RoundCount/Result/单位列表，创建 EventQueue，读取 `TbBattle` 配置，调 CreateUnits 生成双方单位 |
| `StartBattle()` | 开始战斗：触发全局 BattleStart Buff → 广播 OnBattleStart → StartRound() |
| `AddPendingUnit(personId, isPlayerSide, slotIndex)` | 添加待入场单位（入 RoundStart 队列，下一轮开始才出现） |
| `CreateUnitFromEvent(BattleEvent)` | 事件队列调用：按召唤事件参数创建 BattleUnit |
| `TriggerSkill(actor, skillId, targets)` | 供事件队列 TriggerSkill 事件调用，直接执行技能 |
| `NotifyBuffApplied/Removed` | 广播 Buff 事件（供 EventQueue 转发） |
| `CreateUnits(config, tables)` | 从战斗配置读取双方单位表，逐个 CreateBattleUnit/CreatePlayerBattleUnit |
| `CreateBattleUnit/CreatePlayerBattleUnit` | 创建敌方/玩家单位：读 Person/Character 表，组装 Stats/BuffManager/AvailableSkills |
| `StartRound()` | 回合开始五步：①处理召唤事件 ②增援入列 ③处理其他 RoundStart 事件 ④全局 TurnStart Buff ⑤按 FinalSpeed 降序+阵营+槽位排序建 TurnQueue → 广播 → ProcessTurnQueue() |
| `ProcessTurnQueue()` | 循环取出队首存活单位 StartUnitTurn；队空则 EndRound() |
| `StartUnitTurn(unit)` | 单位回合开始：ResetTurnState → 处理 TurnStart 事件/Buff → 广播 OnUnitTurnStart → ProcessStatusCheck |
| `ProcessStatusCheck(unit)` | 状态检查：眩晕/冻结置 SkipAction；TurnStart 治疗类 Buff 生效；跳过则直接 EndUnitTurn，否则 EnterActionPhase |
| `EnterActionPhase(unit)` | 进入行动阶段：处理 Action 事件 + BeforeAction Buff；玩家单位置 IsWaitingForPlayerAction=true 等输入；AI 单位调 BattleAI.Decide 后 ExecuteAction |
| `ExecuteAction(action)` | **行动执行总入口**：解析目标 → 按类型分发（Skill/Item/Defend/Flee）→ AfterAction Buff → 技能走 `presenter.PlaySkillSequence`（演出完回调 CheckDeaths+EndUnitTurn）；非技能直接 CheckDeaths+EndUnitTurn |
| `EndUnitTurn(unit)` | 回合结束：处理 TurnEnd 事件/Buff → 广播 OnUnitTurnEnd → AdvanceTurnQueue |
| `AdvanceTurnQueue()` | 出队 → ProcessTurnQueue（BattleEnd 阶段短路） |
| `EndRound()` | 轮结束：RoundEnd 事件 → 全单位冷却递减 → 全局 TurnEnd Buff → CheckBattleEnd → 未结束则 StartRound |
| `PlayerUseSkill(skillId, targetSlotIndex)` | 玩家技能入口：校验等待态/冷却/可选中/目标有效性 → 设冷却 → 构造 BattleAction（skillId=0 为普攻）→ ExecuteAction |
| `PlayerUseItem(itemId, targetSlotIndex)` | 玩家物品入口：构造 Item 行动 |
| `PlayerDefend()` | 玩家防御：构造 Defend 行动 |
| `PlayerDeferTurn()` | 玩家后移回合：当前单位出队排到队尾（"发呆"按钮） |
| `PlayerFlee()` | 玩家逃跑：校验 Canflee 配置 → 构造 Flee 行动 |
| `ExecuteSkill(actor, skillId, targets)` | 技能结算：普攻（CalcDamage，防御减半）；技能按 SkillType 分派（Heal 治疗 / Physical/MagicDamage 伤害 / BuffOnly）；附带 BuffId 应用；广播 OnSkillExecuted |
| `ExecuteItem/ExecuteDefend/ExecuteFlee` | 物品（应用 Buff + 背包扣除）/防御（IsDefending=true）/逃跑（直接 EndBattle(Flee)） |
| `GetSkillTargets(actor, skillCfg, selectedSlot)` | 按技能配置解析命中单位：Self 返回自身；否则 ExpandRangeSlots 展开范围 + GetTargetsBySide |
| `CanSelectSkillSlot(skillCfg, slot)` | 落点可选性校验（selectable 表） |
| `GetTargetsBySide(type, actor, slotIndices)` | 按阵营解析目标：Self/Ally(自己方)/Enemy(对方)，过滤死亡 |
| `GetTargets(type, actor, slot)` | 兼容旧调用：单槽目标 |
| `ResolveTargets(action)` | 行动目标统一解析：Defend/Flee 返回自身；技能按 ActionId>0 查配置展开范围；否则按 TargetSlotIndices 直接解析 |
| `GetRowUnits/GetColumnUnits/GetAllAliveUnits/GetAllyAliveUnits/GetEnemyAliveUnits` | 阵型/存活查询（行=SlotIndex/3，列=SlotIndex%3） |
| `CalcDamage(attacker, defender)` | 伤害公式：`attacker.FinalDestroy - defender.FinalDestroy/2`，最小 0 |
| `ApplyDamage(unit, damage)` | 伤害应用：护盾吸收 → 扣 HP → HP<=0 置 IsAlive=false → 广播 OnDamageTaken |
| `ApplyHeal(unit, amount)` | 治疗应用：加 HP + ClampHp → 广播 OnHealed |
| `TriggerBuffs(unit, trigger)` | 触发单位 Buff：Heal 类治疗；CounterDamage 类反击（OnHit 时对 CurrentUnit 反伤+附加Buff） |
| `TriggerGlobalBuffs(trigger)` | 遍历所有存活单位触发 Buff |
| `CheckBattleEnd()` | 胜负判定：玩家全灭→Lose；敌方全灭→Win；调用 EndBattle |
| `IsPlayerSideAlive/IsEnemySideAlive` | 阵营存活判定 |
| `CheckDeaths()` | 遍历 HP<=0 单位广播 OnUnitDeath + CheckBattleEnd（演出后调用，见 ExecuteAction） |
| `EndBattle(result)` | 战斗结束：置 Phase=BattleEnd → 全局 BattleEnd Buff → Win 时 ApplyBattleRewards → 广播 OnBattleEnd |
| `ApplyBattleRewards()` | 胜利奖励：经验（CharacterStatsManager.AddExp）/货币/掉落物品（BagManager） |
| `GetUnitAtSlot(playerSide, slotIndex)` | 按槽位查存活单位 |
| `GetAvailableTargetsForSkill(actor, skillId)` | 返回技能所有可选落点（供 AI/UI 用）：逐单位校验 selectable + 命中非空 |
| `GetTables()` | 经 ManagerRegistry 取 DataTableManager 的配置表 |

**事件清单（UI/表现层订阅）**：OnBattleStart / OnRoundStart(int) / OnUnitTurnStart(unit) / OnUnitPhaseChange(unit, phase) / OnUnitActionExecute(unit, action) / OnUnitTurnEnd(unit) / OnRoundEnd(int) / OnBattleEnd(result) / OnDamageTaken(unit, dmg) / OnHealed(unit, amount) / OnBuffApplied / OnBuffRemoved / OnSkillExecuted / OnUnitDeath(unit) / OnUnitDefend(unit) / OnPlayerFlee / OnNewUnitsReady(units)

### 2.3 BattleAI（敌方 AI 决策，静态类）

| 方法 | 功能 |
|---|---|
| `Decide(unit, battle)` | AI 决策主入口：①HP<30% 且有治疗技能→找最低血友军施放 ②否则找最强伤害技能打最优目标 ③无技能则普攻 ④无目标则防御 |

| `FindBestTarget(targets)` | 目标选择：优先前排（row=2）中最低 HP |

### 2.4 BattleEventQueue / BattleEvent（延迟事件系统）

**BattleEventQueue**：

| 方法 | 功能 |
|---|---|
| `Enqueue(evt)` | 事件按 TriggerPhase 入对应队列 |
| `ProcessPhase(phase)` | 处理该阶段全部排队事件 |
| `ProcessUnitPhase(phase, unit)` | 只处理目标为该单位的事件（其余放回） |
| `ProcessPendingSummons()` | RoundStart 队列提取所有 SummonUnit 事件→CreateUnitFromEvent→返回新单位列表 |
| `ExecuteEvent(evt)` | 事件执行分发：Summon（日志）/ApplyDamage/ApplyHeal/ApplyBuff/RemoveBuff/AdjustSpeed/SkipAction/TriggerSkill |
| `Clear()/GetQueueCount(phase)` | 清空/查询队列 |

**BattleEvent**：数据载体（EventType/TriggerPhase/TargetUnit/SourceUnit/Param1/Param2/BoolParam/Data）+ 静态工厂（Summon/Damage/Heal/Buff/RemoveBuff）。

**BattleEventPhase 6 时机**：RoundStart / TurnStart / StatusCheck / Action / TurnEnd / RoundEnd（与 BattleManager 流程中的调用点一一对应）。

### 2.5 BattlePresenter（表现层总控——前端表现核心）

| 方法 | 功能 |
|---|---|
| `PlaySkillSequence(actor, skillId, targets, beforeHp, onComplete)` | **技能演出总入口**：BattleManager 结算后调用；StartCoroutine 播放演出序列，结束回调 onComplete |
| `SkillSequenceRoutine(...)` | 演出协程（对齐策划案 3.5.1 喜剧三拍子），完整时间轴见 §3.2 |
| `OnUnitDeath(unit)` | 订阅死亡事件，启动死亡演出协程 |
| `DeathRoutine(unit)` | 死亡演出：**等 IsPlaying 结束**（防抢跑）→ 等 0.2s 飘字亮稳 → 0.45s 旋转倒地（Z 轴 ±85°）+ 下沉 0.25 → SetActive(false)；_deathCount 归零时 IsDeathPlaying=false |
| `W(seconds)` | 加速感知等待：seconds / _speed（点击加速 1→2.5→8） |
| `GetUnitGo(unit)` | 经 BattleStageManager 取单位 GameObject |
| `FaceTarget(go, targetPos)` | 转身：按目标 X 方向翻转 Sprite（scale.x 取正负） |
| `WindUpRoutine(go, back, dur)` | 蓄力预备：向远离目标后拉 + 压扁拉伸（喜剧铺垫） |
| `MoveRoutine(go, target, dur)` | 平滑位移（SmoothStep 缓动） |
| `FlashWhiteRoutine(go, dur)` | 受击闪白：SpriteRenderer + Spine 骨骼整体变白后还原 |
| `KnockbackRoutine(go, attackerGo, dist, dur)` | 受击后仰：远离攻击者推出再弹回（Sin 曲线） |

状态：Instance 单例 / IsPlaying（演出中，输入抑制）/ IsDeathPlaying（死亡演出中）/ _speed（加速倍率）。
事件：OnSequenceBegin / OnSequenceEnd（BattleWindow 订阅做输入抑制）。

### 2.11 入口与状态（GameApp / BattleGameState / GameStateMachine）

| 方法 | 功能 |
|---|---|
| `GameApp.EnterBattle(battleId)` | **战斗入口**：记录返回场景/前状态 → new BattleManager + 注册 + 订阅 OnBattleEnd → InitBattle → LoadScene("Scene_Battle") |
| `GameApp.OnBattleSceneLoaded()` | 场景加载完成：切 BattleGameState → StageManager.SpawnUnits(全单位, 完成后 StartBattle) → 打开 BattleWindow → 订阅增援入场 |
| `GameApp.OnBattleFinished(battleId, result)` | Win 时记录完成战斗 + 条件系统通知 |
| `GameApp.OnBattleResultConfirmed()` | 关 BattleWindow → 返回原场景 → ExitBattle |
| `GameApp.ExitBattle()` | 清 BattleManager → 恢复战斗前游戏状态 |
| `BattleGameState.Enter()` | 进入战斗状态：输入切 UI-only、玩家 Rigidbody 冻结 |
| `BattleGameState.Exit()` | 退出：恢复输入模式与玩家运动 |
| `GameStateMachine.ChangeState/Update` | 游戏状态机（战斗状态切换） |

## 三、完整战斗流程

### 3.1 战斗生命周期（主流程）

```
GameApp.EnterBattle(battleId)
  → BattleManager.InitBattle(battleId)      # 读配置、建单位
  → SceneController.LoadScene("Scene_Battle")
  → OnBattleSceneLoaded()
      → BattleGameState.Enter()             # 冻结玩家、切UI输入
      → BattleStageManager.SpawnUnits()     # Addressables 加载 Spine 角色 + 血条
      → BattleManager.StartBattle()         # 全局Buff + OnBattleStart
      → UIManager.Open<BattleWindow>()      # 战斗UI
  → BattleManager.StartRound()              # 排序 → TurnQueue
      → 循环: StartUnitTurn → StatusCheck → Action
          ├─ 玩家: IsWaitingForPlayerAction=true (UI操作)
          └─ AI:   BattleAI.Decide → ExecuteAction
      → ExecuteAction → 技能 → Presenter.PlaySkillSequence → 演出完回调
      → CheckDeaths → EndUnitTurn → AdvanceTurnQueue
  → EndRound → CheckBattleEnd
      → EndBattle(Win/Lose/Flee) → OnBattleEnd
  → BattleWindow.WaitPerformancesThenReturn()  # 等演出全完
  → GameApp.OnBattleResultConfirmed() → 返回原场景 → ExitBattle
```

### 3.2 技能演出时间轴（BattlePresenter，对齐策划案 3.5.1）

```
[0.00s] StartPause 0.1s（锁定反馈停顿）
[0.10s] FaceDuration 0.05s 转身（翻转 Sprite X 朝向目标）
[0.15s] WalkDuration 0.25s 走向目标（距离 3/4）
[0.40s] WindUp 0.20s 蓄力预备（后拉 0.25 + 压扁拉伸）
[0.60s] Lunge 0.16s 出招冲刺（0.30 距离）→ StrikePause 0.12s 命中停顿
[0.88s] 受击反馈：每目标 FlashWhite 0.12s + Knockback 0.14s（间隔 HitInterval 0.08s）
[1.02s] ComedyDelay 0.15s 喜剧延迟（受击完停顿再飘字）
[1.17s] 飘字（DamageFx，间隔 0.05s）+ 血条白条残影（PlayGhostAnimation 0.7s）
[2.40s] Return 0.25s 归位 + 恢复朝向
── 点击加速: 1 → 2.5 → 8（W() 感知加速）
── 死亡演出（OnUnitDeath 触发）: 等 IsPlaying → 0.2s → 0.45s 倒地(rot±85°+下沉0.25) → 隐藏
```

### 3.3 事件驱动关系（谁订阅谁）

```
BattleManager (18事件)
  ├─ BattlePresenter:   OnUnitDeath → DeathRoutine（倒地演出）
  ├─ BattleWindow:      13事件 → 日志/血条/按钮/指示器/选中标签
  │                      OnSequenceBegin/End → 输入抑制
  ├─ GameApp:           OnBattleEnd → OnBattleFinished（存档/条件）
  └─ BattleStageManager:（不订阅，由 BattleWindow 调 UpdateHealthBar）

UI操作链路:
  玩家点击"暴力行为" → BattleWindow.OnViolenceClicked → BattleSkillPanel.Open
    → 点技能 → OnSkillSelected → PlayerUseSkill(skillId, 游标目标槽位)
      → ExecuteAction → 结算 → PlaySkillSequence（UI 按钮隐藏）→ 演出完 → EndUnitTurn
```

## 四、关键设计决策（含历史修复）

| 决策 | 说明 |
|---|---|
| 演出回调推进回合 | 技能结算后不立即 EndUnitTurn，等 PlaySkillSequence 的 onComplete——保证飘字/倒地完整（修复：死亡倒地抢跑） |
| 死亡演出防抢跑 | DeathRoutine 先 `while (IsPlaying)` 等当前演出序列结束再倒地 |
| 战斗结束等演出 | BattleWindow.WaitPerformancesThenReturn 等 IsPlaying+IsDeathPlaying 结束再返回场景（修复：场景卸载截断倒地） |
| 事件队列延迟处理 | 召唤/伤害/治疗等事件可指定 6 个时机之一触发，支持增援入场 |
| 飘字渲染 | WorldSpace Canvas + worldCamera=Camera.main + 字号 80/110 + 父级 lossyScale 位移 + 不设 Billboard（修复：飘字不可见/飞出屏幕） |
| 全局选中中心点 | 玩家回合方向键随时切换目标，点技能直接对当前游标目标释放，无效置灰（3.2 动态选择轻量版） |
| 表现层解耦 | BattlePresenter 经 ManagerRegistry/单例取依赖，不反向依赖 Assembly-CSharp |
